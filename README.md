# Голубые заметки

Простое учебное Flutter-приложение для работы с заметками.

## Возможности

- добавление заметки;
- вывод заметок в виде списка;
- редактирование;
- удаление с подтверждением;
- проверка пустого ввода;
- голубое оформление Material 3.

Заметки хранятся в памяти во время работы приложения.

## Запуск

```bash
flutter pub get
flutter run
```

## Проверка

```bash
flutter analyze
flutter test
```
